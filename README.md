# EventFlow

Event-driven processing platform built with Node.js,
TypeScript and NestJS.

## Overview

EventFlow is an educational open-source project focused
on distributed systems, asynchronous processing,
reliability and observability.

## Planned Stack

- NestJS
- TypeScript
- PostgreSQL
- RabbitMQ
- Redis
- Docker
- OpenTelemetry
- Prometheus
- Grafana
- GitHub Actions

## Status

Under development — Phase 1: Project Foundation.
